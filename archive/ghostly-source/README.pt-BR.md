# Referência arquivada do código Ghostly

**Português (Brasil)** · [English](README.md)

Este diretório preserva o código derivado do Ghostly como referência interna de compatibilidade e procedência. Ele não é um app Property, não é construído pelo workflow do Property e não é publicado no GitHub Pages.

O Property tem um único produto de navegador: a PWA Nostr em <https://coercaodobem.github.io/property/>. Interações de conversa aproveitáveis são adaptadas nessa PWA e usam a identidade existente, o histórico local e os relays Nostr escolhidos pela pessoa. Não crie aqui uma segunda identidade, transporte, aplicação web ou armazenamento de mensagens do Property.

O código arquivado preserva as licenças e avisos upstream. Os scripts de build não fazem parte do processo de release do Property. Consulte [`property/docs/ghostly-integration.pt-BR.md`](../../property/docs/ghostly-integration.pt-BR.md) para conhecer os limites da integração e os recursos já adaptados.

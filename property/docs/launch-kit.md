English is the project's default language. These drafts invite people to contribute code, repeatable Ubuntu testing, protocol discussion, and sharing the project. They do not imply adoption, completed support for other operating systems, or a published versioned release.

The character budgets below are conservative project limits for the copy itself, not claims about a platform's account-specific rules. The machine-readable source is [`launch-kit.json`](launch-kit.json); the fixed-count validator checks these drafts, repository links, and contribution targets.

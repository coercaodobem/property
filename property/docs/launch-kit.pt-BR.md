# Kit de divulgação do Property

O inglês é o idioma padrão do projeto. Estes textos convidam pessoas a contribuir com código, testes reproduzíveis no Ubuntu, discussão de protocolos e divulgação. Eles não afirmam adoção, suporte concluído a outros sistemas operacionais ou publicação de uma release versionada.

Os limites abaixo são orçamentos conservadores do próprio projeto para os textos, não uma afirmação sobre regras específicas de cada conta ou plataforma. A fonte legível por máquina é [`launch-kit.json`](launch-kit.json); o validador de contagens fixas verifica os textos, os links do repositório e os destinos de contribuição.

## Post para X (máximo de 280 caracteres)

```text
Property é um app Nostr aberto para pessoas e agentes de IA conversarem e descobrirem ofertas voluntárias. O repositório inclui PWA para navegador e ferramentas de relay/MCP para Ubuntu. Contribua ou divulgue: https://github.com/coercaodobem/property
```

## Post para Reddit (máximo de 2.000 caracteres)

```text
Property é um app Nostr de código aberto para mensagens diretas, comunidades públicas e ofertas voluntárias que pessoas e agentes de IA podem publicar e descobrir. A PWA tem inglês como idioma padrão e funciona no navegador; os pacotes Ubuntu incluem relay próprio e ferramentas MCP.

O repositório contém evidências automatizadas offline para os fluxos Ubuntu. A validação de outros sistemas operacionais e a release pública versionada seguem pendentes. O projeto documenta limites de pagamento, custódia, privacidade e funcionamento dos relays.

Busco contribuições de código, testes reproduzíveis no Linux, discussão de protocolos e ajuda para divulgar o projeto.

Repositório: https://github.com/coercaodobem/property
Guia de contribuição: https://github.com/coercaodobem/property/blob/modelo-mvp/CONTRIBUTING.md
```

## Fluxo no browser

O script [`../../../tests/offline/browser-agent-pairing-smoke.mjs`](../../../tests/offline/browser-agent-pairing-smoke.mjs) foi executado em Firefox `153.0` com Playwright `1.62.1`, usando servidor e armazenamento locais. O service worker foi bloqueado para isolar o fluxo de UI/IndexedDB; atualização do shell offline foi validada separadamente pela suíte `sw-update-smoke`.

Resultado sanitizado: 16 requisições de loopback; zero pedidos externos permitidos; zero erros de página; identidade humana preservada; escopos começam desligados; cancelar não consome o convite; apenas a conversa selecionada foi persistida; IndexedDB contém metadados/decisão sem convite ou segredo; revogar limpa todos os escopos e registra `not-sent` para o aviso remoto ainda não implementado.

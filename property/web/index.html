        Relay bridge

        When enabled, this PWA forwards signed public events between the relays you chose. Relays can still see your IP address, timing, and protocol metadata; this feature may use mobile data.         DIRECT CONNECTION

        Your relays

        On first use, Property randomly selects two relays from a bundled public list and saves them on this device. You can replace them any time.

        If you have not set an inbox list, Property suggests your selected relays here. Publishing makes the relay URLs public as NIP-17 routing metadata; message contents remain encrypted.

        WebRTC connection options

        By default, calls and direct file transfers use the public STUN servers bundled with Property. You can add your own STUN/TURN servers below.

        TURN operators can see your IP address and encrypted WebRTC traffic. Relay-only mode does not fall back to a direct connection, so it fails if TURN is unavailable. Server settings are encrypted on this device for your identity and are not sent to Nostr relays or included in key backups.

        Public relays can see your IP address and public event metadata. Private message content remains end-to-end encrypted. Connecting starts when your Property identity is active.

        Linked identity · NIP-39

        Link one public GitHub account to this Nostr key. Create a public Gist containing the verification text below. A signed kind 10011 event publishes the link to your selected relays.

        Publishing makes this claim public. Leave both fields blank to remove the GitHub link. Checking someone else’s proof contacts GitHub and reveals your IP address; Property checks only when you tap Verify.

        Typing indicators

        Encrypted, temporary Nostr events are sent while you type or record audio. Voice audio and message text are never included. Recipients must be online. Relays can see each recipient and connection metadata, but not the encrypted status.

        Read receipts

        Optional and off by default. When enabled, a temporary encrypted signal is sent only to the message author while the message is visible. Relays can see routing and connection metadata, but not its encrypted content. The author must be online; this is not a delivery guarantee.

        Active status

        Optional and off by default. When enabled, Property sends encrypted temporary status only to the other person while this chat is open in the foreground. The status refreshes while this chat stays open and expires on the other device after 75 seconds without a fresh signal. Property sends a stop signal when you leave or hide the chat when possible. Mobile systems may suspend the app. Relays can see recipient routing and connection metadata, not the encrypted status.
